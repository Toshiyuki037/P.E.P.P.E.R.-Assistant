## 📌 Overview

P.E.P.P.E.R. is a persistent AI engineering assistant built to move beyond the traditional chatbot workflow.

Instead of requiring every problem to be manually copied into an AI interface, P.E.P.P.E.R. combines voice, vision, workspace context, persistent memory, tools, and multi-step agent execution to work alongside me directly.

It can inspect engineering work, reason about problems, navigate the local development environment, modify files with authorization, execute tools, and verify the result.

> **The goal: turn AI from something I interact with into something I can work alongside.**
